# Design thinking, the last step: implementation

Written in `## Implementation`, from the creator's words and results, never invented.

1. **Test plan** (if the test has not run): five to seven people, one task each, the success
   criterion fixed before the test ("4 of 5 finish alone"), who watches.
2. **Feedback to collect**: what, by which channel, where it comes back in the file, dated.
3. **From learning to product**: one line per learning ("what we learned → what to do", with its
   source); the creator picks one gesture per line, you never choose:
   - **hypothesis**: one `review.critique` (`agent: stella`, `kind: idea`, `lenses: ["socratic"]`,
     `summary` the test; each finding `severity: should_fix`, `claim` the learning as a checkable
     statement, `passage` `design-<slug>`, `argument` the observation, `proposal`, `proof` the plan's measure); then the gestures of
     `.agentplugged/skills/test-idea/references/personas.md`. `critique_unsorted`: sort the earlier stack first.
   - **story**: one line ("<who> can <do what> so that <why>"), kept with `plan.defer`
     (`origin: deliberate`, `owner: creator`, `title` the line, `detail` the learning and source).
   - **drop**, with their reason in the file.
4. **Pilot**: who, how long, the one metric and its date, when to stop.
