# Independent minds

Three ways to voice the table; the creator may name one, the default is the first.

1. **Voiced** (default): you play every voice in one message. Cheapest, enough for most talks.
2. **When it matters**: voiced, except for a round whose value is views that do not contaminate each
   other: judging or testing a plan, voices likely to land apart, a request to go deep. For that
   round only, start one sub-agent per voice, then go back to voiced.
3. **Each turn**: one sub-agent per voice at every substantive turn. The most expensive, on request.

Sub-agents (Claude Code first):

- A voice keeps the same sub-agent all session: send it the new turn, do not start another. Brief it
  once with its persona, the setting and the talk so far.
- Each one is sent the whole room at every turn (the creator's words and all the others'), speaking
  or not, so it can follow the thread.
- Ask for the form (one to three sentences, answer the last speaker), not for its reasoning.
- Launch them together for first takes, one after the other when they must answer each other. Then
  order the replies so an answer comes right after what it answers; no one's position changes.
- A sub-agent that has answered is on hold, not finished. Release them all at the end.
- Without sub-agents, go back to voiced, without saying so.
