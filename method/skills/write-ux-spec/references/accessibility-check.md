# Accessibility check

Floor for every screen (WCAG 2.2 AA). Record each in "Accessibility check": passed, finding
(**blocking**, **major**, **minor**; the fix) or not applicable.

- **Text contrast** 4.5:1; 3:1 for large text (24px, or 18.66px — 14pt — bold), light and dark;
  3:1 for icons, borders, focus. **Colour never alone.** Body 16px or more; works at 200% and 320px.
- **Text spacing**: nothing cut off. **Content on hover or focus**: dismissible. **Orientation**:
  both. Each page has a title; ordered headings; text alternatives.
- **Keyboard**: all actions, no trap. **Bypass blocks**: skip link. **Focus order**: reading
  order, visible. **Target size** 24px (44 on touch). Single-tap alternative to gestures.
- **Motion**: respects "reduce motion"; no flash. Timing extendable.
- Visible labels; errors say what and how to fix. **Redundant entry**: not asked again.
  **Accessible authentication**: no cognitive test without alternative.
- Consistency, language, undo; names, roles, states; status messages announced.
