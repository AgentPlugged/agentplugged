# Mock-up pages

The specification wins over a page; `ux.md` says so once in "Brand and style".

- Flat files of `.agentplugged/docs/ux-mockups/`, eight at most, from `assets/mockup-page.html`
  (no script or link; tokens as CSS custom properties). `docs check` reports faults.
- `directions.html`: two or three whole looks on one screen.
- `screen-<slug>.html`, drawn by a sub-agent that returns the path. Ask once which screens need
  one; `none` in the "Mock-up page" cell for the rest.
