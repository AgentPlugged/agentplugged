# UX specification checklist

Run before showing it.

- Header `id: ux`, `kind: ux`, `owner: stella`, `links`; no `status`, `cost`, `progress`; no
  identifier defined; no placeholder, comment, answered `[open: G-…]` or template sample
  (`#FFFFFF`, `#0F62FE`, `16px`…) unless chosen. `docs check` clean.
- Every journey has a key flow; every screen serves one, lists its states, has a numbered sketch;
  nothing asks for what the PRD does not state; every `{…}` is defined.
- Every accessibility item has a result; no blocking finding unfixed.

## Excess (over-specification)

Each a finding; for a verdict, a sub-agent runs `judgment` (skill `critique-deliverable`).

- **One home per value.** An inline value a token names.
- **One home per fact.** PRD content its identifier carries.
- **A reader per section.** A section nobody builds from goes.
- **Reachable.** A screen or state that no journey of the PRD reaches.
