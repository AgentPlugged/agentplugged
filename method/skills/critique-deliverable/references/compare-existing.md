# Compare with the existing

Set the document beside what already exists, and see where it re-invents, contradicts or
forgets.

1. Gather what exists: the code and documents in the repository, the products the users
   already use, the creator's earlier decisions. Read only what the document touches.
2. For each major point, ask: does something here already do this, and does the document agree
   with it (names, limits, behaviour, constraints)?
3. Keep the contradictions, the duplicates, and the existing things the document would break.

Each is an objection: the mismatch is the `claim`, the passage is the `passage`, and the place
where the existing thing can be seen (a file, a screen, a product) is the `proof`.
