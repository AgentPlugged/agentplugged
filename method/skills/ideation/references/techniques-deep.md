# Deep: reach what lies under the question

For a full diagnosis of a problem that resists, the skill `strategy` (`PS`) goes further.

- Five whys: ask "why?" on one answer, five times, each feeding the next. Use when the stated problem is a symptom.
- Question storm: only questions, no answers, until there are twenty; then keep the ones worth answering. Use when the question itself is unsure.
- Hidden rules: list the unwritten rules of the field and break one on purpose. Use when every idea looks alike.
- Pre-mortem: it is a year later and it failed; write why, then turn each cause into an idea. Use before committing to a direction.
- Provocation: state something absurd ("the product has no users") and pull a usable idea out of it. Use to leave a rut.
- Zoom: go up one level ("what is this for?") and down one ("what is the first step?") from the same idea. Use when the goal and the means are mixed up.
- Contradiction hunt: name what improves and what worsens, and look for a way to get one without the other. Use when every option costs something.
- Grid of options: list the parts of the product, several options for each, then read across for combinations. Use to explore a design space.
