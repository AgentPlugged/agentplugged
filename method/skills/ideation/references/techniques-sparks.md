# Sparks: leaps that break the usual path

- What if: remove one limit at a time (money no object, the reverse is true, the problem has vanished). Use for a cold start or a stuck frame.
- Analogy: "this is like what?"; borrow the way out from the field that already solved its twin. Use when the problem has a twin elsewhere.
- Ground rules: strip every assumption down to known facts, then rebuild. Use when the idea feels inherited.
- Forced pairing: draw two unrelated things and force a bridge until an idea appears. Use when ideas stay in one corner.
- Name game: give the product ten different names; each name implies a different idea of it. Use to see what it could be.
- Image swap: describe the problem as if it were a kitchen, a city or a game; the way that world copes becomes the idea. Use for a vague, big subject.
- Blend: merge two ideas into a hybrid and name what it is. Use to invent an offer, not improve one.
- Senses: ask what the idea would look, sound, feel and smell like in use. Use when the ideas are all abstract.
