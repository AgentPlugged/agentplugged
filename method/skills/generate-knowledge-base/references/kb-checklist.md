# Knowledge base checklist

Run every check before showing the base to the creator. Fix what fails; when a fix needs the
creator, ask them.

## Headers

- Each page starts with its header: `id: kb-…`, `kind: note`, `owner: zoe` and `links`.
- Every `id` is unique in `.agentplugged/docs/` and made of lowercase letters, digits and
  hyphens.
- `links` names only documents and active requirements that exist.
- No `status`, `state`, `cost`, `spent`, `budget_spent` or `progress` key.
- No "Generated by agentplugged" line, no guidance comment and no `<…>` placeholder left.
- `sources` lists each validated document of the method the page was built from, with the blob
  of the version read; only documents of `.agentplugged/docs/` (brief, PRD, UX, architecture
  and decisions) go there. Drafts, stories, epics, other pages of the base and files of the
  repository stay out of it: stories and epics are not tracked. Release notes carry no
  `sources`.
- `npx agentplugged docs check` reports no problem, and no `kb_stale` nor
  `kb_source_unrecorded` warning.

## Coverage

- The map, `.agentplugged/docs/index.md`, lists every page of the base, and every page it lists
  exists.
- The base covers the vision, the requirements, the architecture, the decisions, the
  conventions, at least one guide (getting started) and the release notes, or the map says in
  one line why a topic has no page yet.
- Each page answers one question, and its first lines give the answer.

## Truth

- Each page has a **Sources** section, and every claim comes from one of its sources.
- Each source document carries the date its end of phase was approved, or "draft".
- Every command, version and path was checked in the repository.
- No requirement or decision is copied: the page points to the PRD or the architecture.
- No identifier opens a line, a list item, a heading or a first table cell.
- A page drawn from the repository defines no identifier.
- No secret, token or personal datum appears in a page.
- What no file proved is listed under **Open questions**, not written as a fact.

## Form

- Each page carries `Last updated: <date> — <what changed it>` under its title. After an
  update, the reason names the validated document and its checkpoint ("PRD validated in G-…").
- An update changed only the pages a warning named, and in them only the passages the new
  version touches.
- Short sentences, plain words; tables and diagrams rather than long prose.
- Written in the creator's language, headings included.
